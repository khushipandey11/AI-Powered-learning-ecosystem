# AI Learning Ecosystem

An AI-powered learning platform developed using Python and Gemini 2.5 Flash.

## Features

- AI-generated notes
- AI-generated quizzes
- Exportable notes and quizzes
- PDF-based AI doubt solving

## Tech Stack

- Python
- Django
- Gemini 2.5 Flash API

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Configure the required environment variables in `.env`.
5. Run migrations:
   ```
   python manage.py migrate
   ```
6. Start the server:
   ```
   python manage.py runserver
   ```
